# liste des options du model

liste des options personnalisées du modèle de document

| Nom de la variable  | Étiquette de l'option                    | Type          |
| :------------------ | :--------------------------------------- | :------------ |
| `printdominicales`  | Afficher les messes dominicales et fêtes | case à cocher |
| `printquotidiennes` | Afficher les messes quotidiennes         | case à cocher |
| `printconfessions`  | Afficher les confessions                 | case à cocher |
| `debug`             | Debug (utiliser la visualisation HTML)   | case à cocher |
